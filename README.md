# Tom Smith

Bioinformatician in the [Biological Mass Spectrometry and Proteomics Facility](https://mrclmb.ac.uk/facilities/mass-spectrometry/) at the [MRC Laboratory of Molecular Biology](https://mrclmb.ac.uk/), Cambridge. I analyse proteomics and transcriptomics data and (occasionally) develop software.

[ORCID](https://orcid.org/0000-0002-0697-8777) · [Google Scholar](https://scholar.google.com/citations?user=uUSIeLAAAAAJ&hl=en) · [Email](mailto:tsmith@mrclmb.ac.uk)

### Software

- [**biomasslmb**](https://lmb-mass-spec-compbio.github.io/biomasslmb/): R package for building proteomics data analysis pipelines with `QFeatures` ([code](https://github.com/lmb-mass-spec-compbio/biomasslmb))
- [**UMI-tools**](https://github.com/CGATOxford/UMI-tools): tools for handling Unique Molecular Identifiers in NGS data sets ([paper](https://doi.org/10.1101/gr.209601.116))
- [**simulate_trna**](https://github.com/MRCToxBioinformatics/simulate_trna): a generic tRNA-Seq read simulator ([paper](https://doi.org/10.7554/eLife.96955))

### Analyses

- [**LoRNA_UPR**](https://github.com/CambridgeCentreForProteomics/LoRNA_UPR): relocalisation of RNA and protein in response to activation of the Unfolded Protein Response
- [**BPAF uptake in *Caulobacter crescentus***](https://github.com/lmb-mass-spec-compbio/BPAF_uptake_Caulobacter_crescentus_TMT_proteomics): timecourse TMT proteomics ([paper](https://doi.org/10.1038/s41592-026-03109-7))
- [**PER2 and mTOR**](https://github.com/lmb-mass-spec-compbio/PER2_HALO_PROTAC): PER2-HALO and PER2-PROTAC proteomics ([preprint](https://doi.org/10.64898/2026.08.28.747564))
